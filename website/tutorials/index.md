# Tutorials

Eight short lessons build the library up from nothing. They assume you
know Python and nothing at all about MeTTa. Each lesson introduces one
idea with runnable code and a rendered picture of what the code made,
and ends where the next lesson begins.

1. [Atoms and expressions](./01-atoms-and-expressions.md) starts with one atom and builds symbols, variables, and expressions in Python.
2. [Spaces and matching](./02-spaces-and-matching.md) stores facts in a space and asks patterns against them.
3. [Equations and evaluation](./03-equations-and-evaluation.md) gives matching expressions rewrites and runs them to answers.
4. [The Python bridge](./04-python-bridge.md) chooses between `run`, `eval`, and `query` from the value you already have.
5. [Writing MeTTa in Python](./05-writing-metta-in-python.md) compiles decorated Python functions into equations.
6. [Types and casting](./06-types-and-casting.md) declares optional types and checks values against them with `cast`.
7. [Seeing your program](./07-seeing-your-program.md) reads traces, lint results, and derivations.
8. [The graph view](./08-graph-view.md) draws terms as connected nodes and animates a reduction.
