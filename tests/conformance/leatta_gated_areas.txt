# The LeaTTa per-area promotion list. tests/conformance/leatta.py
# --gate-areas-file reads this. One area name per line PROMOTES it to GATE:
# from then on, if that area has even one differing checkable file, the
# leatta lane fails check.sh outright, the same way every other GATE line
# there does. '#' starts a comment, inline or whole-line; blank lines are
# ignored. An area named here that tests/conformance/leatta.py does not
# find under LeaTTa's tests/semantics/ is a hard error, not a silent no-op,
# so a typo cannot silently gate nothing.
#
# An area NOT listed here still runs on every check.sh, still prints its
# differences in full, and can never fail the run by itself: the REPORT
# tier check.sh already documents, just scoped to one area instead of the
# whole lane.
#
