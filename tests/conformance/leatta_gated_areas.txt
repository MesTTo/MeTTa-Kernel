# The LeaTTa per-area promotion list. tests/conformance/leatta.py
# --gate-areas-file reads this. One area name per line PROMOTES it to GATE:
# from then on, if that area has even one differing checkable file, the
# leatta lane fails check.sh outright, the same way every other GATE line
# there does. '#' starts a comment, inline or whole-line; blank lines are
# ignored. An area named here that tests/conformance/leatta.py does not
# find under LeaTTa's tests/semantics/ is a hard error, not a silent no-op,
# so a typo cannot silently gate nothing.
#
# An area NOT listed here still runs on every check.sh, still prints its
# differences in full, and can never fail the run by itself: the REPORT
# tier check.sh already documents, just scoped to one area instead of the
# whole lane.
#
# Promoting an area is a claim, so promote it only once
#   PY=/home/user/Dev/.venv-pypetta/bin/python
#   "$PY" tests/conformance/leatta.py --area NAME --gate
# exits 0 with LeaTTa checked out. Uncomment its line below in the same
# commit that makes the claim true, and say in the commit message what now
# holds.
#
# The gate reads the STATUS now: a file whose status is `diverges` or
# `ours` is the arbiter's committed ruling, its difference is the recorded
# state, and it cannot block a promotion; only a file that CLAIMS agreement
# while differing blocks. So an area promotes at zero BLOCKING files, and
# the burn-down's finish line is per-area and real.
#
# Measured 2026-08-20 on the promotion rule above (305 files total, 238
# checkable; run `"$PY" tests/conformance/leatta.py --area NAME --show 500`
# per area). Nothing below qualifies yet, and the BLOCKING column is the
# distance:
#
#   area              agreeing / checkable   blocking (claim agreement, differ)
#   ----------------  --------------------   ----------------------------------
#   control-stdlib      2 / 13                7 of 11 differing
#   eval-core          12 / 27                8 of 15   (1 more file is prose-only)
#   grounded           10 / 35               17 of 25

#   metaprogramming     1 / 9                 6 of 8

#   spaces              6 / 17                7 of 11
#   types-basic        42 / 76               14 of 34
#   types-meta         12 / 20                3 of 8    (7 more files prose-only)
#
# matching and types-meta are three blocking files from promotion each, and
# modules five; the committed divergences and the undecided no longer stand
# in the way, which is what the status-reading gate exists for.
